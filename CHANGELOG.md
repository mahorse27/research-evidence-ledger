# Changelog

All notable changes are documented here. This project follows Semantic Versioning.

## [0.1.0] - 2026-08-10

### Added

- Dependency-free Python CLI with `init`, `add`, `validate`, `render`, and `summary` commands.
- Evidence categories for literature facts, formal inferences, hypotheses, and evidence gaps.
- Stable entry IDs, cross-entry basis validation, DOI format checks, and strict audit mode.
- Markdown rendering, JSON Schema, example ledger, tests, and Python 3.10-3.13 CI.
- MIT license, contribution guidance, security policy, and public roadmap.
